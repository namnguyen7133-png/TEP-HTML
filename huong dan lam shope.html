Affiliate Shopee A-Z Guide Game

Game hướng dẫn cầm tay chỉ việc từ lúc chọn sản phẩm tới kiếm tiền và theo dõi hoa hồng.

A. Chuẩn bị công cụ

  1. Máy tính / Laptop có trình duyệt (Chrome, Edge, Cốc Cốc…)
  2. File HTML Affiliate CSV Analyzer
  3. Tài khoản Shopee Affiliate đã đăng ký
  4. File Excel / Google Sheet để lưu link và thông tin sản phẩm

B. Lấy sản phẩm

Bước 1 — Truy cập Shopee Affiliate

  • Vào: https://affiliate.shopee.vn/offer/product_offer
  • Đăng nhập tài khoản

Bước 2 — Chọn sản phẩm

  1. Duyệt các ngành hàng / tìm từ khóa sản phẩm
  2. Tích chọn các sản phẩm muốn làm affiliate

Bước 3 — Lấy link CSV

  • Bấm “Lấy link hàng loạt” → Shopee tải về file CSV chứa:
    • Tên sản phẩm
    • Giá
    • Hoa hồng
    • Link sản phẩm
    • Link affiliate

C. Phân tích và chọn sản phẩm

Bước 4 — Mở file HTML

  • Nhấp đúp file Affiliate CSV Analyzer.html → mở bằng trình duyệt

Bước 5 — Tải CSV vào hệ thống

  1. Bấm Chọn file CSV → chọn file CSV từ Shopee
  2. Bấm Tải CSV
  3. Hệ thống hiển thị tất cả sản phẩm với: Giá, hoa hồng, % hoa hồng, doanh thu, shop, link sản phẩm, link affiliate

Bước 6 — Lọc sản phẩm

  1. Chọn hoa hồng tối thiểu (ví dụ ≥ 3.000₫)
  2. Chọn doanh thu/số bán tối thiểu (ví dụ ≥ 5k+)
  3. Bấm Lọc → hiển thị sản phẩm phù hợp

Bước 7 — Gợi ý TOP 10 sản phẩm

  • Bấm Gợi ý TOP 10 theo bộ lọc → hệ thống chọn 10 sản phẩm tốt nhất dựa trên công thức:
    • Điểm = Hoa hồng × 1.0 + Số bán × 0.2 + (% hoa hồng × 10)
  • Những sản phẩm này dễ bán + thu nhập ổn định

D. Lưu và quản lý link

Bước 8 — Ghi lại thông tin

Tạo file Excel / Google Sheet:

Tên sản phẩmGiáHoa hồngSố bánShopLink sản phẩmLink affiliate
... điền sản phẩm đã chọn ...

E. Quảng bá sản phẩm

Bước 9 — Chọn kênh

  • Mạng xã hội: Facebook, TikTok, Instagram, Zalo
  • Website / Blog: Review, hướng dẫn, so sánh giá
  • Video: TikTok / YouTube → giới thiệu sản phẩm
  • Email marketing: Gửi danh sách sản phẩm tới khách hàng

Bước 10 — Đăng và theo dõi

  • Mỗi link affiliate → theo dõi: Số click, đơn hàng phát sinh, hoa hồng thu về

F. Tối ưu chiến dịch

  • Tập trung vào TOP 10 gợi ý → dễ bán, hoa hồng ổn định
  • Thử nghiệm nhiều kênh → chọn kênh bán tốt nhất
  • Điều chỉnh: Thời gian đăng bài / video, nội dung thu hút, giá hiển thị / khuyến mãi

G. Lặp lại hằng tuần

  • Shopee cập nhật hoa hồng, sản phẩm hot → tải CSV mới
  • Chọn TOP 10 mới → cập nhật link → tiếp tục quảng bá

Tip quan trọng: Không quảng bá tất cả sản phẩm cùng lúc → tập trung TOP 5–10 sản phẩm dễ bán nhất. Kết hợp file HTML để lọc + gợi ý TOP 10 → tiết kiệm thời gian và tăng thu nhập ổn định.
